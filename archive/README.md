# Archived Bringup Snapshots

Historical kernel recipes, standalone diagnostic patches, and bringup records from early ASUS Zenbook A16 (`UX3607OA` / `glymur`) enablement prior to the two-track (`stable` and `rc`) packaging architecture.

- [`kernel/`](kernel/): Retired kernel build recipes (`rc3-20260919`, `rc5-20261002`, `rc5-20261008`, `rc5-20261013`).
- [`patches/`](patches/): Retired patch queues (`next-20260807`, `next-20260817`, `rc3-20260919`, `rc5-20261002`, `rc5-20261008`) and [`standalone/`](patches/standalone/) one-off patches.
- [`boot-records/`](boot-records/): Retained text diffs and register state records from early hardware bringup.

For active kernel builds and patches, use [`../kernel/stable/`](../kernel/stable/README.md), [`../kernel/rc/`](../kernel/rc/README.md), [`../patches/stable/`](../patches/stable/README.md), and [`../patches/rc/`](../patches/rc/README.md).
